
# Python 象棋 (Xiangqi) AI 遊戲

這是一個使用 Python 和 Pygame 函式庫開發的中國象棋 (Xiangqi) 遊戲。遊戲特色是包含了一個基本的 AI 對手，讓你可以與電腦對弈。棋盤和棋子使用 UTF-8 字符繪製。  
  
我是用gemini-2.5-pro協助加入AI功能。  
  
## 主要功能

*   **圖形化棋盤:** 使用 Pygame 繪製視覺化的象棋棋盤與棋子。
*   **基本象棋規則:** 實現了大部分中國象棋的棋子移動規則，包括：
    *   將/帥 (General): 在九宮內直線移動。
    *   士/仕 (Advisor): 在九宮內斜線移動。
    *   象/相 (Elephant): 田字移動，不能過河，會被塞象眼。
    *   馬/傌 (Horse): 日字移動，會被蹩馬腿。
    *   車/俥 (Chariot): 直線移動，無距離限制，路徑中不能有棋子。
    *   砲/炮 (Cannon): 直線移動，吃子時需要隔一個棋子（炮台）。
    *   卒/兵 (Pawn): 過河前只能前進，過河後可前進或橫走，不能後退。
    *   飛將規則：將和帥在同一直線上且中間無棋子時，可以直接吃掉對方（AI 會避免產生此非法局面）。
*   **玩家對弈 AI:** 玩家執紅棋 (下方)，AI 執黑棋 (上方)。
*   **基本 AI:** 使用 Minimax 演算法配合 Alpha-Beta 剪枝來決定 AI 的走法。
*   **可調 AI 難度:** 可以透過修改程式碼中的 `AI_DEPTH` 變數來調整 AI 的搜尋深度（預設為 3），數值越高 AI 越強，但思考時間也越長。
*   **操作提示:** 選中棋子後會顯示可移動 (綠色框) 和可攻擊 (黃色框) 的位置。
*   **狀態顯示:** 遊戲視窗頂部會顯示當前輪到誰走棋以及 AI 的思考狀態。

## 環境需求

*   **Python:** 3.x 版本
*   **Pygame:** 需要安裝 Pygame 函式庫。
*   **字型:** 需要系統安裝支援顯示中文字符（特別是象棋棋子字符）的字型。程式會嘗試載入常見字型 (如 MingLiu, SimSun, WenQuanYi Micro Hei, PingFang SC 等)，若無法正常顯示棋子，可能需要手動指定或安裝合適的字型。

## 如何執行

1.  **取得程式碼:** 下載或複製 `chess_ai.py` 檔案。
2.  **安裝 Pygame:** 如果你尚未安裝 Pygame，請打開終端機或命令提示字元，執行：
    ```bash
    pip install pygame
    ```
3.  **執行遊戲:** 在終端機或命令提示字元中，切換到 `chess_ai.py` 檔案所在的目錄，然後執行：
    ```bash
    python chess_ai.py
    ```

## 基本操作

*   **移動游標:** 使用鍵盤的 **上、下、左、右箭頭鍵** 移動紅色的選擇框。
*   **選擇棋子:** 將游標移動到你想操作的**紅色**棋子上方，按下 **Enter (回車鍵)**。如果該棋子有合法的移動或攻擊位置，會在棋盤上以綠色（移動）或黃色（攻擊）框標示出來。
*   **移動/吃子:** 再次移動游標到標示出的**綠色**或**黃色**方框位置，按下 **Enter (回車鍵)** 確認移動或吃子。
*   **取消選擇:** 如果選中棋子後想反悔，按下 **Esc (退出鍵)** 可以取消選擇。
*   **結束遊戲:** 當一方的將/帥被吃掉後，遊戲結束，頂部會顯示勝負結果。此時按下 **Esc (退出鍵)** 可以關閉遊戲視窗。

## AI 功能說明

*   **演算法:** AI 使用 **Minimax 演算法**來預測未來的幾步棋。它會假設玩家 (紅方) 也會選擇對 AI 最不利的走法，並從中選擇一個對 AI 自己來說最優的結果。
*   **優化:** 為了提高效率，AI 使用了 **Alpha-Beta 剪枝**技術。這可以讓 AI 在不影響最終決策的情況下，跳過很多明顯不好的可能性，從而加快思考速度或增加思考深度。
*   **評估函數:** AI 判斷局面好壞主要是基於一個簡單的**評估函數** (`evaluate_board`)，它會計算雙方現存棋子的基本價值總和，並給過河的兵卒額外加分。分數越高，表示對 AI (黑方) 越有利。
*   **思考深度 (`AI_DEPTH`):** 這個數值決定了 AI 會往前推算多少步 (一個回合算一步)。數值越大，AI 越能考慮長遠的影響，棋力通常越強，但計算所需時間也越長。預設值 3 提供了一個平衡的體驗。你可以修改原始碼中的 `AI_DEPTH = 3` 來調整。

## 副程式 (Function) 功能說明表

| 副程式名稱                      | 主要功能說明                                                     |
| :------------------------------ | :--------------------------------------------------------------- |
| `plotBoard()`                   | 繪製遊戲主畫面，包括棋盤線條、棋子、標題、狀態訊息等。           |
| `plotCursor(x, y)`              | 在指定的 `(x, y)` 座標繪製玩家的紅色選擇框。                     |
| `plotMarker(x, y, color)`       | 在指定的 `(x, y)` 座標繪製指定顏色的標示框（基礎函數）。         |
| `plotCandidate(x, y)`           | 在指定的 `(x, y)` 座標繪製綠色的可移動位置標示框。               |
| `plotAttack(x, y)`              | 在指定的 `(x, y)` 座標繪製黃色的可攻擊位置標示框。               |
| `get_piece_at(x, y, p_black, p_red)` | 檢查指定的 `(x, y)` 座標是否有棋子，並返回棋子資訊和顏色。         |
| `find_valid_moves(piece, p_black, p_red)` | 計算**單個**指定棋子的所有合法移動和攻擊位置，考慮象棋規則和飛將限制。 |
| `get_all_legal_moves_for_side(p_black, p_red, side)` | 計算指定**一方** (黑方或紅方) **所有**棋子的**所有**合法移動和攻擊列表。 |
| `evaluate_board(p_black, p_red)` | 評估當前的棋盤局面，給出一個分數（正分有利於黑方 AI，負分有利於紅方）。 |
| `minimax(p_black, p_red, depth, alpha, beta, maximizing_player)` | 實現 Minimax 搜尋演算法與 Alpha-Beta 剪枝，遞迴地找出最佳走法。   |
| `make_ai_move()`                | 協調 AI 的回合：呼叫 `minimax` 找到最佳走法，然後在棋盤上執行該走法。 |

## 已知限制與未來改進方向

*   **AI 評估函數簡單:** 目前的評估函數主要基於子力，可以加入更多位置評估、棋子協同、王的安全等因素來增強 AI。
*   **未實現完整勝負判斷:** 目前僅以將/帥是否被吃掉判斷勝負，未實現「將軍」、「應將」、「困斃」（Stalemate）等更完整的象棋規則判斷。
*   **無開局庫/殘局庫:** AI 沒有使用常見的開局走法或殘局資料庫。
*   **性能:** 搜尋深度較高時，AI 思考時間會明顯增加。
